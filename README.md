# Operations Research Projects and Tools

Welcome to the **Operations Research (OR)** repository! This repository contains models, algorithms, tools, and notes related to Operations Research, with a focus on solving complex decision-making and optimization problems using mathematical methods and computational techniques.

## 🔍 What is Operations Research?

Operations Research is a discipline that applies advanced analytical methods to help make better decisions. It encompasses a wide range of mathematical techniques such as:

- Linear and Integer Programming
- Network Optimization
- Simulation
- Decision Analysis
- Game Theory
- Heuristics and Metaheuristics
- Supply Chain Optimization
- Scheduling and Resource Allocation

## 📌 Objectives

- Showcase practical applications of OR in logistics, manufacturing, supply chain, and more.
- Implement classical and modern optimization algorithms.
- Provide reproducible examples using open-source tools like Python (PuLP, Pyomo, Gurobi, etc.)
